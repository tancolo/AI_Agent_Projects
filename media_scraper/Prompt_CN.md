# 中文Prompt 脚本升级V0.2
将脚本重构为通用的配置化媒体抓取工具，具体要求如下：
1. 各种文件中关于Ayumi Hamasaki以及她的日文名字，需要改成变量，方便修改， 项目中Python文件名字就不能是ayumi_hamasaki之类的，要用通用名字的替代。

3. **配置化驱动 (Config-based)**：采用类似 Git 的配置文件格式（如 INI 格式）来动态读取抓取任务。

5. **媒体类型切换**：支持选择抓取 `Audio`（音频）或 `Video`（视频）。
6. **多格式封装**：支持 `mp3`, `webm`, `mp4` 等多种格式，默认封装格式为 `webm`。
7. **下载质量控制**：
   - **音频 (Audio)**：允许设定码率（如 320kbps），默认下载最高码率。

4.  **执行流程**：不要急于写代码。首先充分理解需求，输出详细的升级策略和执行计划（保存为V0.3版本的文档）供审查。
