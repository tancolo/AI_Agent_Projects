## 📥 How to Install

Since this is a Beta version and not yet on the Chrome Web Store, you will need to load it manually.

1.  **Unzip the file**: Extract the `MapleWay_Beta_v0.1.zip` file to a folder on your computer (e.g., your Desktop).
2.  **Open Extensions Page**:
    *   Open Google Chrome.
    *   Type `chrome://extensions` in the address bar and press Enter.
3.  **Enable Developer Mode**:
    *   Look at the **top right corner** of the page.
    *   Toggle the switch for **"Developer mode"** to **ON**.
4.  **Load the Extension**:
    *   A new menu will appear at the top left.
    *   Click the **"Load unpacked"** button.
    *   Select the folder you just unzipped (the one containing `manifest.json`).

## ✅ Success!
You should now see the **MapleWay** icon <img src="./codebase/VanillaJS/icons/icon16.png" width="16" style="vertical-align: middle;"/> in your browser toolbar. Click it to open the popup and start testing.
